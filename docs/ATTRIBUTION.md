# Attribution guide

The dataset is licensed under CC BY-NC 4.0. Attribution should identify MeloLingua, the dataset title, version, repository, and license. If you modify the material, state that changes were made.

## Plain text

> MeloLingua CEFR-Graded Multilingual Stories Dataset, version 1.0.0, MeloLingua, 2026. https://github.com/MeloLingua/melolingua-language-stories-dataset — CC BY-NC 4.0.

## Academic citation

Use the repository's `CITATION.cff` metadata or the BibTeX example in the README. Include the version or commit hash you used. Add the DOI after a Zenodo archive is available.

## Individual stories

Each record has a `canonical_url` pointing to its original lesson on melolingua.com. When discussing or reproducing one story, include that URL as well as the dataset citation.

## No endorsement

Do not imply that MeloLingua reviewed, certified, or endorses your adaptation. The MeloLingua name and logo are not licensed as branding.
