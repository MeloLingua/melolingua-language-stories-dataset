# Changelog

All notable dataset changes are documented here.

## [1.0.0] - 2026-08-27

### Added

- 118 public A1–B2 MeloLingua graded stories
- German, Spanish, French, Italian, Korean, and Russian story records
- Sentence-aligned English translations, vocabulary, comprehension activities, notes, and sentence-building exercises
- Story, sentence, vocabulary, and question CSV views
- Canonical source URLs, source hashes, semantic hashes, and provenance
- JSON Schema, automated validation, citation metadata, and distribution cards
